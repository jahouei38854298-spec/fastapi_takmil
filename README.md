
# پروژه مدیریت کاربران با FastAPI و MongoDB

## معرفی پروژه

این پروژه با استفاده از Python، FastAPI و MongoDB ساخته شده است و امکان مدیریت کاربران را از طریق API و یک صفحه وب فراهم می‌کند.

قابلیت‌های فعلی پروژه:

- نمایش فهرست کاربران در جدول HTML
- افزودن کاربر جدید
- ویرایش سن کاربران
- حذف کاربران
- جست‌وجو و فیلتر کاربران بر اساس نام و سن
- مرتب‌سازی کاربران بر اساس نام یا سن
- صفحه‌بندی نتایج API
- اعتبارسنجی اطلاعات ورودی
- ذخیره اطلاعات کاربران در MongoDB

## پیش‌نیازها

پیش از اجرای پروژه، موارد زیر باید نصب باشند:

- Python
- pip
- MongoDB
- محیط مجازی Python

نصب Visual Studio Code اختیاری است.

## نصب و راه‌اندازی

### ۱. ورود به پوشه پروژه

در ترمینال وارد پوشه پروژه شوید:

```bash
cd ~/Desktop/fastapi
```

### ۲. ساخت محیط مجازی

اگر محیط مجازی از قبل ساخته نشده است، دستور زیر را اجرا کنید:

```bash
python3 -m venv .venv
```

### ۳. فعال‌سازی محیط مجازی

```bash
source .venv/bin/activate
```

### ۴. نصب پکیج‌ها

```bash
python -m pip install -r requirements.txt
```

## راه‌اندازی MongoDB

اطمینان حاصل کنید سرویس MongoDB فعال است:

```bash
sudo systemctl start mongod
```

برای بررسی وضعیت سرویس:

```bash
sudo systemctl status mongod
```

برنامه از دیتابیس `fastapi_db` و مجموعه `students` استفاده می‌کند.

تنظیم اتصال در فایل `database.py` قرار دارد:

```python
client = MongoClient("mongodb://localhost:27017/")
db = client["fastapi_db"]
students_collection = db["students"]
```

## اجرای پروژه

درحالی‌که محیط مجازی فعال است، دستور زیر را اجرا کنید:

```bash
python -m uvicorn main:app --reload
```

صفحه مدیریت کاربران:

http://127.0.0.1:8000

مستندات API:

http://127.0.0.1:8000/docs

## نحوه استفاده

### مدیریت کاربران از طریق صفحه وب

در صفحه اصلی می‌توانید:

- با واردکردن نام و سن، کاربر جدید اضافه کنید.
- سن کاربر را تغییر دهید.
- کاربر را حذف کنید.
- فهرست کاربران را در جدول مشاهده کنید.

### استفاده از API

مستندات تعاملی API در مسیر `/docs` در دسترس است.

مسیرهای اصلی:

| متد | مسیر | کاربرد |
|---|---|---|
| GET | `/students` | دریافت فهرست کاربران |
| GET | `/students/{name}` | دریافت اطلاعات یک کاربر |
| POST | `/students` | افزودن کاربر |
| PUT | `/students/{name}` | ویرایش اطلاعات کاربر |
| DELETE | `/students/{name}` | حذف کاربر |

مسیرهای صفحه وب نیز برای افزودن، ویرایش سن و حذف کاربران استفاده می‌شوند.

## فایل‌های مهم پروژه

- `main.py` — برنامه اصلی و مسیرهای FastAPI
- `database.py` — اتصال به MongoDB
- `templates/index.html` — صفحه HTML مدیریت کاربران
- `requirements.txt` — پکیج‌های Python همراه با نسخه آن‌ها
- `README.md` — راهنمای نصب و استفاده
- `students.json` — فایل قدیمی اطلاعات کاربران که برای پشتیبان نگه داشته شده است
- `students_backup.json` — نسخه پشتیبان اطلاعات پیش از انتقال

## نکات مهم

- سرویس MongoDB باید هنگام اجرای برنامه فعال باشد.
- برای نصب وابستگی‌ها از فایل `requirements.txt` استفاده کنید.
- فایل‌های JSON را تا زمانی که از صحت پشتیبان مطمئن نشده‌اید حذف نکنید.
